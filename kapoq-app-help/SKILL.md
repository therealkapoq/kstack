# Kapoq App Help

## Overview

The Kapoq Help Center is the source of truth for how the Kapoq web app works:

**https://intercom.help/kapoq-helpcenter/en/**

Answer Kapoq questions from its articles, fetched live, and link the articles you used. Kapoq's screens, setting names, defaults, and rules differ from Amazon's, Walmart's, and other ad tools' own consoles, so general marketplace knowledge is not a substitute.

## How to answer

1. **Search the Help Center directly.** Fetch `https://intercom.help/kapoq-helpcenter/en/?q=<terms>` (URL-encode the terms, e.g. `?q=budget+automation`). Use the feature's name rather than the user's phrasing where you can. Results link to `/kapoq-helpcenter/en/articles/...`; prefix `https://intercom.help`. Go straight to this URL - a general web search mixes in other vendors' docs.
2. **Read the 1-3 most relevant articles for each part of the question** (a two-part question may need a second search). Prefer feature articles; a title alone can mislead, so cite an article only if it actually answered something. Use Release Notes articles for "what changed", "when did X ship", or "is X new".
3. **Answer from the articles.** Use their names for screens, menus, and settings. End with the links to each article you used.
4. **No hit?** Retry with synonyms, or open the matching collection below and scan its article titles.
5. **Still nothing?** Say the Help Center does not cover it and suggest the user contact Kapoq support. If you add anything from general Amazon/Walmart knowledge, label it as such - never present it as Kapoq behavior.

## Common mistakes

| Mistake | Instead |
|---------|---------|
| Answering from memory or generic Amazon Ads knowledge | Fetch the article first; Kapoq defaults and menu paths are specific |
| Running a general web search for "Kapoq ..." | Use the Help Center's own `?q=` search URL |
| Citing an article you did not open | Only link articles you actually read |
| Guessing a menu path the article does not give | Quote the article's path, or say it is not documented |
| No web-fetch or browsing tool available (after checking for one your client can load on demand) | Tell the user, and give them the Help Center link and the search URL for their question |
